# Network-Computing-Assignment6

这个项目包含两个网络计算任务的C++实现。

## Task1: 桥接器（Bridge）实现

Task1.cpp 实现了一个简单的以太网桥接器，用于处理LAN帧。

- **功能**：
  - 定义LAN帧结构，包含目的地址、源地址和端口。
  - 桥接器类维护地址表，学习源地址。
  - 处理帧转发：广播泛洪、未知地址泛洪、同端口丢弃、已知地址转发。

- **测试**：包含多个测试用例，演示桥接器的学习和转发行为。

## Task2: WiFi接入点部署和信号强度热图

Task2.cpp 生成WiFi接入点的部署方案并计算信号覆盖。

- **功能**：
  - 生成18个接入点的位置（3层楼，每层6个AP）。
  - 为每个AP分配2.4GHz和5GHz频道。
  - 计算信号强度，考虑距离衰减、墙壁衰减和楼层衰减。
  - 生成热图显示信号覆盖区域（+++ 表示良好覆盖，--- 表示弱覆盖）。

- **输出**：显示AP部署表和三层楼的信号热图。

## 编译和运行

使用g++编译：
```
g++ Task1.cpp -o bin/Task1.exe
g++ Task2.cpp -o bin/Task2.exe
```

运行：
```
./bin/Task1.exe
./bin/Task2.exe
```
